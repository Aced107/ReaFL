# ReaFL

FL Studio-style tools for REAPER's arrange view. Switch tools with one key and click
items the way you would in FL Studio's playlist.

## Current tools (v0.1.0)

| Key | Tool    | What the mouse does |
|-----|---------|---------------------|
| `1` | Default | Normal REAPER behaviour. |
| `T` | Mute    | **Left click** an item: toggle its mute (selection is not changed). **Right click** an item: delete it. Clicking empty space, or Ctrl/Alt/Win + click, behaves like normal REAPER. |

A small floating **ReaFL** toolbar shows which tool is active (the active button is lit).
REAPER always starts in the Default tool.

Every mute or delete is one undo step ("ReaFL: Mute item", "ReaFL: Unmute item",
"ReaFL: Delete item").

Notes on the Mute tool:
- A double click counts as two clicks, so the item's mute ends where it started, as in FL.
  REAPER's own double-click action (for example, opening an editor or plug-in) is blocked.
- Left drag on an item does not move it while the Mute tool is on. Switch to Default (`1`)
  to move items.

## Requirements

- REAPER 7.03 or newer (Windows, macOS or Linux)
- [ReaPack](https://reapack.com)
- **js_ReaScriptAPI**: required for the Mute tool's clicks. Install it in ReaPack
  (Extensions > ReaPack > Browse packages, search "js_ReaScriptAPI"). It comes from the
  *ReaTeam Extensions* repository, which ReaPack includes by default. Restart REAPER afterwards.
- SWS extension: recommended, not required.

## Install

1. In REAPER: **Extensions > ReaPack > Import repositories...** and paste
   ```
   https://raw.githubusercontent.com/Aced107/ReaFL/main/index.xml
   ```
2. **Extensions > ReaPack > Browse packages**, search **ReaFL**, right-click > Install, then Apply.
3. **Actions > Show action list**, run **ReaFL - Setup (run once after install)**.
   Setup:
   - binds `1` to the Default tool and `T` to the Mute tool (any existing binding on those
     keys in the Main section is replaced and remembered);
   - adds a "ReaFL" floating toolbar in the first free toolbar slot;
   - adds a small guarded block to `Scripts/__startup.lua` so REAPER always starts in the
     Default tool;
   - backs up every file it changes to `<REAPER resource path>/ReaFL_backups/`.
4. **Restart REAPER.** REAPER only reads shortcuts and toolbars at startup. The toolbar
   opens by itself the first time.

Running Setup again is safe; it only fixes whatever is missing.

## Uninstall

1. Run **ReaFL - Uninstall setup**. It removes the shortcuts (and restores any you had on
   `1`/`T`), the toolbar and the startup block. Then restart REAPER.
2. To remove the scripts, uninstall the ReaFL package in ReaPack.

## Updating

ReaPack updates ReaFL with the rest of your packages (Extensions > ReaPack > Synchronize packages).

## For developers

`index.xml` is generated by `tools/build_index.py` (no Ruby needed):

```
python3 tools/build_index.py                       # GitHub URLs -> index.xml
python3 tools/build_index.py file:///path/to/ReaFL/ /tmp/index-local.xml   # local test
```

Bump `VERSION`, `TIME` and `CHANGELOG` in the script (and the header in `ReaFL/ReaFL.lua`)
for each release.
